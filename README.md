# Data-Visualization
The goal of this task was to translate the cleaned stock price dataset into clear, professional visualizations that highlight market trends, stock distributions, and feature relationships.
Title: Task 3 - Basic Data Visualization & Insights

Technical Implementation
Trend Analysis: Developed Line Charts to compare the 5-year price trajectory of high-volume stocks (e.g., AAPL, MSFT, AMD).

Categorical Comparison: Created Bar Plots to rank the S&P 500's most liquid assets by average daily trading volume.

Correlation & Relationship Mapping: * Designed a Scatter Plot to visualize the inverse relationship between stock price and trading volume.

Constructed a Heatmap to identify multi-collinearity between Open, High, Low, and Close prices.

Customization & Export: Applied professional styling using seaborn.set_theme(), customized axis labels for readability, and exported high-resolution PNGs (300 DPI) for reporting.

Key Tools
Matplotlib: For figure architecture and fine-tuned customization.

Seaborn: For advanced statistical visualizations and color mapping.
